## Lessons

1. **A named catalyst is a commitment, not a suggestion.** The Aug 14 file used the specific
   phrase "named catalysts... therefore become review obligations." FOMC Minutes on Aug 20 was
   in that list by name. Not running the morning review today means we had no written read on
   what the Fed's Minutes said about the September rate path, which is the single macro variable
   our cautious posture is most sensitive to. If the Minutes were dovish (reducing hike odds),
   there should have been a posture update. If hawkish, that reinforces the cautious posture and
   should be documented. We got neither. The lesson: a review obligation written into a decisions
   file must be treated as a standing task, not aspirational.

2. **SPY falling on FOMC day is not a signal in isolation — but not checking at all is a
   failure of process.** The gap between our return (0.00%) and SPY's (+1.60% as of tonight)
   narrowed today because SPY dropped. That could mean some of the froth the Aug 14 file
   described (SPY 10%+ above 200-day average, CAPE ~39x) is deflating. Or it is a single-day
   noise event. We cannot tell because we did not run the review. The process exists precisely
   so that days like this — when the market actually moves on a scheduled catalyst — produce a
   written record of what changed and what we did with that information.

3. **Jackson Hole begins tomorrow (Thu Aug 21), also a named review obligation from Aug 14.**
   Five consecutive weekdays will have elapsed with no morning decision file. Jackson Hole
   speeches historically move rate expectations; our entire cautious posture is built on those
   expectations. The morning review on Aug 21 is not optional. If the process does not run
   tomorrow, we will have missed both FOMC Minutes and the opening of Jackson Hole without a
   written response.
